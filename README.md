# BubblesTheDev GitHub Pages website

A static, responsive website. No build tools, packages, analytics, or backend required.

## Published website

This repository is designed to publish from the root of the `main` branch with GitHub Pages.

Website: `https://kernferm.github.io/BubblesTheDev/`

In the repository's **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Google Play website verification

- Google Play Console may require Search Console ownership verification.
- In Google Search Console, add a **URL-prefix property** for your exact published GitHub Pages URL.
- Select **HTML tag** verification. Copy the provided `<meta name="google-site-verification" content="...">` tag into the `<head>` of `index.html`, commit the change, wait for deployment, and click Verify in Search Console.
- HTML-file verification can also work when a verification file is placed at the exact site root.
- Use the verified URL in Play Console and follow the prompts. Verification is not guaranteed until Google confirms it.

## Before using publicly

- Review app descriptions and any planned price/status information.
- The Google Play developer listing URL may need adjustment if your public developer name differs.
- The website privacy page covers **this static website only**, not your Android applications. Do not use it as an app privacy policy without verifying app-specific practices.
- Do not publish your residential address or personal phone number in this website's source files.
- A website does **not** replace Google Play's trader/contact disclosures.
